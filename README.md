Inspired by the cosmos, this pack of color themes contains several different themes (light, dark, and high-contrast) to customize your VSCode window, code syntax, and more.

I created and use these personally because I found that I wanted different colors for various syntax to make my coding experience easier. I also wanted an improved color scheme for my editor.

Semantic highlights are shared across theme types. That is, all dark themes have the same semantic highlights. This ensures consistency across all themes of similar types. There are elements of the window that are accented based on the particular theme.

> Can be found at the [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=jtpeller.nebulous-color-themes).

The contents of the extension are kept intentionally small. The VSIX file containing only what is necessary (notice the difference when images are included!)

## Color Themes

These are the themes available in this VSCode Extension:

### Dark Themes

#### "Deep Space" (Dark)

The **Deep Space** theme is a "deep space" theme which is darker than the default VS Code dark theme, with modifications for additional contrast between key pieces of the code syntax.

<img src="assets/images/theme-deepspace.png" alt="Deep Space Theme Sample Image" style="display: block; margin-left: auto; margin-right: auto; width: 85%;"/>

#### "Boundless Void" (Black)

The **Void** theme is an even darker version of the "Dark" theme. It is generally darker than the Deep Space theme. All accent colors are greyscale (to a reasonable degree; for instance, certain functional color schemes like Git remain colored).

<img src="assets/images/theme-void.png" alt="Boundless Void Theme Sample Image" style="display: block; margin-left: auto; margin-right: auto; width: 85%;"/>

#### "Engraved Hourglass" Nebula (Red)

The **Engraved Hourglass** theme is based upon the "Void" theme, except those greyscale accents are red. This is based upon my new favorite nebula, the Engraved Hourglass Nebula. The center looks like an eyeball, and it's fascinating.

<img src="assets/images/theme-engravedhourglass.png" alt="Engraved Hourglass Nebula Theme Sample Image" style="display: block; margin-left: auto; margin-right: auto; width: 85%;"/>

### Light Themes

#### "Sol" (White)

The **Sol** theme is a white theme inspired by the Sun. It utilizes a unique set of colors for the code syntax and the entire window.

<img src="assets/images/theme-sol.png" alt="Sol Theme Sample Image" style="display: block; margin-left: auto; margin-right: auto; width: 85%;"/>

#### "Luna" (Silver)

The **Luna** theme is a darker variant of the **Sol** theme, aiming to be more gray and muted, similar to the moon.

<img src="assets/images/theme-luna.png" alt="Luna Theme Sample Image" style="display: block; margin-left: auto; margin-right: auto; width: 85%;"/>

#### "Supernova" (Void Light)

The **Supernova** theme is the light-color alternative to the "Void" themes. It is a high-contrast, brilliant white theme representing the high-energy light of a stellar explosion, accented with electric blues.

<img src="assets/images/theme-supernova.png" alt="Supernova Theme Sample Image" style="display: block; margin-left: auto; margin-right: auto; width: 85%;"/>

#### "Quasar" (Violet Light)

The **Quasar** theme is a vibrant light theme inspired by the high-energy emissions of galactic nuclei. It features a sophisticated violet-to-blue accent shift, providing a cool and modern coding environment.

<img src="assets/images/theme-quasar.png" alt="Quasar Theme Sample Image" style="display: block; margin-left: auto; margin-right: auto; width: 85%;"/>

#### "Nebular Mist" (Pastel Light)

The **Nebular Mist** theme is a soft, pastel light theme inspired by the diffused gases and dust of distant nebulae. It uses a gentle lavender and mint palette to provide a low-strain, ethereal coding environment.

<img src="assets/images/theme-nebularmist.png" alt="Nebular Mist Theme Sample Image" style="display: block; margin-left: auto; margin-right: auto; width: 85%;"/>

#### "Red Giant" (Warm Light)

The **Red Giant** theme provides a warm, low-strain light environment. Inspired by the deep hues of an expanding star, it features crimson and burnt orange accents over a soft, warm-white background.

<img src="assets/images/theme-redgiant.png" alt="Red Giant Theme Sample Image" style="display: block; margin-left: auto; margin-right: auto; width: 85%;"/>

### High Contrast Themes

#### "Pulsar" (High Contrast Light)

The **Pulsar** theme is the high-contrast light variant of the Nebulous collection. Designed for maximum accessibility, it features sharp borders and a high-contrast color palette, representing the intense radiation of a pulsar star.

<img src="assets/images/theme-pulsar.png" alt="Pulsar Theme Sample Image" style="display: block; margin-left: auto; margin-right: auto; width: 85%;"/>

#### "Abyss" (High Contrast Black)

The **Abyss** theme is the high-contrast dark variant of the Nebulous collection. Designed for maximum accessibility, it features sharp borders and a high-contrast color palette, representing the immense emptiness of the universe.
